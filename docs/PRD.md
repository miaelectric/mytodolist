## 1. 개요

### 1.1 제품 한 줄 소개
브라우저에서 바로 여는 개인용 할 일 관리 앱입니다. 설치, 계정, 서버가 필요 없고 데이터는 브라우저(localStorage)에 저장됩니다.

### 1.2 배경
- 처음에는 모바일 화면에 맞춘 단일 열 레이아웃이었고, 몇 가지 결함이 있었습니다.
  - 정의되지 않은 함수를 호출해서 저장할 때마다 오류가 기록됐습니다.
  - 검색창이 동작하지 않았습니다.
  - 대시보드 수치가 갱신되지 않았습니다.
- 사용자 요청에 따라 단계적으로 확장했습니다.
  1. 기능 완성과 사용성 극대화
  2. 키워드 기반 자동 카테고리 분류
  3. 데스크톱 전체 화면 레이아웃
  4. 데스크톱 최적화 점검과 보완
  5. 모바일·데스크톱 버전을 반응형 단일 버전으로 통합

### 1.3 목표
1. 할 일을 **빠르게 입력하고**, 원하는 기준으로 **정리해서 보고**, 실수해도 **되돌릴 수 있게** 합니다.
2. 휴대폰부터 대형 모니터까지 **한 코드베이스**로 각 화면에 맞는 배치를 제공합니다.
3. 키보드와 스크린 리더 사용자도 모든 기능을 쓸 수 있게 합니다.
4. 데이터를 잃지 않게 합니다. 백업·복원, 손상 데이터 보존, 저장 실패 알림을 제공합니다.

### 1.4 비목표(범위 밖)
- 계정, 로그인, 서버 동기화, 여러 기기 간 공유
- 마감일, 알림, 반복 일정, 하위 작업
- 사용자 정의 카테고리(카테고리는 업무·개인·공부로 고정)
- 빌드 도구, 프레임워크, 패키지 매니저 도입

## 6. 성공 지표(검증 기준)
- 자동화 테스트(헤드리스 Edge)가 모두 통과합니다: 회귀 32개, 자동 분류 34개, 드래그 6개, 가져오기 시나리오 13개
- 레이아웃 측정 기준(4장)을 충족합니다.
- 실제 브라우저에서 수동으로 확인할 항목: TASK.md의 "수동 확인 필요" 참고

## 7. 알려진 제약
- 브라우저 기본 드래그 앤 드롭은 모바일 터치에서 동작하지 않습니다(키보드 이동은 가능).
- 데이터는 브라우저와 기기별로 따로 저장됩니다. 옮길 때는 내보내기/가져오기를 씁니다.
- 할 일 내용을 수정하는 기능이 없습니다(백로그).
